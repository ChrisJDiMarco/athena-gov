# ATHENA — Complete Build Blueprint
## UX/UI Specification for Every Tab + Technical Stack

**Version:** 2.0
**Date:** March 31, 2026
**Status:** Design Complete — Ready for Development

---

## Design Philosophy

Every ATHENA interface is built around a single principle: **decision support at the speed of events.** The interface is not a dashboard you browse — it is a briefing room you work in. Information is prioritized by urgency and consequence, never by recency. The visual grammar is aerospace-grade: dark, precise, data-dense, but never cluttered.

**Visual system:**
- Background: `#040609` (near-black with a blue undertone)
- Primary surface: `#0a0f1a`
- Secondary surface: `#0f1829`
- Accent blue: `#00d4ff`
- Warning amber: `#f59e0b`
- Critical red: `#ef4444`
- Positive green: `#22c55e`
- Typography: Inter (UI) + JetBrains Mono (data/code)
- Grid: 4-column layout — icon rail (48px) + nav sidebar (240px) + main content (flex) + context panel (360px)

### Tab 1: Executive Dashboard

**Purpose:** The opening screen. Everything important at a glance in under 30 seconds.

**Layout:** 3-row grid

**Row 1 — World State Bar (full width)**
- CHI radar chart (hexagonal, all 6 dimensions rendered as colored spokes)
- Current global CHI score (large, centered: "61.9")
- Delta from last 24h (green +0.3 or red -0.7)
- 6 dimension scores in a horizontal row beneath

**Row 2 — Center: Interactive World Map**
- Full-color SVG world map, dark ocean, muted land
- Country hotspots colored by CHI relevance (amber = attention, red = crisis, green = stable)
- Hover: country name, CHI score, top active advisory
- Click: opens World Intelligence tab filtered to that country

**Row 2 — Right: Top 5 Active Advisories**
- Each advisory card: urgency score (1–10, colored), title (≤8 words), domain icon, age
- Red ATHENA badge if adversarial challenge completed
- Click → opens advisory in Tab 3

**Row 3 — Live Feed + Metrics Row**
- Left: scrolling live event feed — new data, completed research, skill earned, agent status changes
- Center: Federal Budget snapshot (total spend YTD vs. appropriation, debt clock)
- Right: Agent fleet health bar — how many of 47 agents are active/busy/idle

### Tab 2: World Intelligence

**Purpose:** Deep geopolitical and country-level intelligence.

**Layout:** Full-screen interactive map + slide-out country panel

**Map layer:**
- Same world map as Tab 1 but full-viewport
- Layer toggles along the top: Military / Economic / Climate / Public Health / Diplomatic / Conflict
- Each layer recolors countries using a domain-specific scoring system
- Active conflict zones shown with animated pulse overlays
- UN peacekeeping operations, NATO presence, and US military footprint as optional overlays

**Country Intelligence Panel (opens on click, 480px right panel):**
- Header: flag, country name, capital, government type, current leader
- CHI sub-scores for that country (mini radar)
- "US Relationship Score" — a composite of trade, treaty, military, diplomatic engagement

- Economic summary: GDP, growth rate, debt, inflation, key exports
- Scroll-down: full intelligence brief generated by ForeignPolicyAgent on demand

**Search bar (top):** Natural language — "Show me countries where climate stress is creating political instability"

### Tab 3: Active Advisories

**Purpose:** The primary working document — every active recommendation from ATHENA.

**Layout:** Filterable list (left 40%) + full advisory (right 60%)

**List panel:**
- Sort by: Urgency / Date / Domain / Confidence
- Filter: Domain / Urgency threshold / Status (open/acted/dismissed)
- Each row: urgency badge (color), title, domain icon, date, Red ATHENA indicator, confidence %
- Keyboard shortcut (↑↓) to navigate, Enter to open

**Full Advisory Panel:**
- Header: Title, domain, urgency (1–10), confidence (0–100%), date issued
- **Situation Summary** — 2–4 sentences describing the problem/opportunity
- **Evidence Base** — bullet list of supporting data points with source citations and confidence weights
- **Recommendation** — the specific action ATHENA advises
- **Implementation Steps** — ordered list of concrete steps
- **CHI Impact Projection** — which CHI dimensions affected, by how much, over what time horizon
- **Simulation Result** (if run) — probability distribution of outcomes, collapsible chart
- **Red ATHENA Debate** (if triggered) — expandable transcript of the adversarial challenge + ATHENA's response + confidence adjustment
- **Dissenting Agent Views** — any agents that voted against this recommendation, with their reasoning
- **Historical Precedents** — 2–3 comparable historical situations with outcomes
- **Risk Factors** — what could make this recommendation wrong
- **Confidence Decomposition** — where the uncertainty comes from (data quality, model uncertainty, political uncertainty)
- Action bar: Accept → Export to brief / Dismiss → Log with reason / Flag → Send to oversight API

### Tab 4: Congress & Legislation

**Purpose:** Real-time legislative intelligence.

**Layout:** 3-column (bill list + bill detail + member intelligence)

**Column 1 — Bill Tracker:**
- Active bills sorted by ATHENA priority score (not just recency)
- Status pipeline: Introduced → Committee → Floor → Conference → Presidential
- Each bill: number, title, priority score, CHI impact forecast, days in current stage
- Search + filter by: sponsor, committee, domain, CHI impact, party alignment

**Column 2 — Bill Detail (on select):**
- Full title, sponsors, co-sponsors
- Plain-language summary (AI-generated)
- Section-by-section analysis
- CBO score if available
- ATHENA's recommendation: Support / Oppose / Amend / Monitor
- Projected CHI impact per section
- Lobbyist interests mapped to this bill (from FARA/lobbying disclosure data)
- Campaign contributions from bill-adjacent industries to key sponsors
- Coalition likelihood: which members are likely yes/no/undecided (with confidence)
- Historical comparison: most similar past legislation and its outcomes

**Column 3 — Member Intelligence:**
- Select any member of Congress
- Party, state, district, committee memberships
- Voting history heatmap (last 4 years, coded by ATHENA alignment)
- Financial disclosures: stock holdings, campaign donors
- Staff key contacts
- Recent public statements (last 30 days)
- ATHENA's behavioral model: predicted vote on any current bill
- "Persuasion gap" — what evidence would most likely change their vote

**Coalition Builder (bottom panel):**
- Input: target bill passage
- Output: which 5–10 members are most persuadable, what their concerns are, suggested language amendments to win each

### Tab 9: Simulation Theater

**Purpose:** Run any policy, economic, or geopolitical scenario before advising.

**Layout:** Simulation builder (left) + results (center) + archive (right)

**Simulation Types:**
- Economic: CGE model for fiscal/monetary policy changes
- Social: Agent-based population modeling for policy impacts
- Geopolitical: Game-theoretic scenario for diplomatic/military decisions
- Climate: IPCC-integrated models for climate policy
- Crisis: Stress tests for infrastructure, financial, public health crises
- Long-range: 25-year consequence mapping for major structural decisions

**Simulation Builder:**
- Type selector (tabs)
- Natural language input: "What happens if we raise the minimum wage to $20/hour nationwide?"
- Parameter controls appear dynamically based on detected simulation type
- Run time estimate
- "Run" button → triggers SimulationEngine agent

**Results Display:**
- Probability distribution of primary outcome (histogram)
- Top 3 most likely scenarios with detailed narrative
- CHI impact breakdown across all 6 dimensions × 5 time horizons (1y, 5y, 10y, 20y, 50y)
- Sensitivity analysis: which inputs most affect the outcome
- Comparable historical situations: how similar decisions played out
- ATHENA confidence with decomposition

**Archive (right panel):**
- All past simulations, searchable
- Outcome tracking: did real events match the simulation?
- Calibration score: how well ATHENA's models perform over time

### Tab 10: MetaClaw Evolution Engine

**Purpose:** Observe and understand ATHENA's self-evolution in real time.

**Layout:** Skill library browser + calibration charts + live evolution feed

**Skill Library Browser:**
- All skills sorted by domain, date acquired, usage count
- Each skill: name, domain, acquisition date, trigger conditions, success rate
- Search: "show me all skills involving economic modeling"
- Skill detail: what ATHENA learned, from which advisory interaction, how confidence improved

**Evolution Metrics:**
- Line charts: Accuracy over time (by domain), Calibration score, Skill library size
- Current stats: total skills, accuracy this month, calibration percentile
- Trajectory visualization: launch → month 6 → year 1 → year 3 → year 10 projections

**OMLS Status (Opportunistic Meta-Learning Scheduler):**
- Last LoRA fine-tune run: timestamp, duration, training samples, improvement delta
- Next scheduled window: estimated time
- LoRA health: loss curve from last training run

**Live Evolution Feed:**
- Streaming log of skills being synthesized in real time

- Highlight when fast adaptation vs. slow LoRA yields different skill types

**Failure Analysis:**
- Advisories where ATHENA's recommendation was later assessed as wrong
- What ATHENA learned from each failure

### Tab 11: Research Observatory

**Purpose:** Monitor autonomous research pipelines in real time and browse archived research.

**Layout:** Active pipelines (top 60%) + archive browser (bottom 40%)

**Active Pipeline Viewer:**
- Each active research run shown as a progress bar across 17 stages
- Stage names shown: Scope → Prior Art → Lit Survey → Screen → Extract → Simulate → Case Study → Synthesize → Challenge → Revise → Quantify → Graph Update → Skill Synthesis → Draft → Review → Deliver → Reflect

**Research Run Detail (click any run):**
- Full metadata: trigger question, spawned by (user query / autonomous gap detection / Red ATHENA request), date started
- Stage-by-stage log: what each stage found, what was discarded, why

- Knowledge graph nodes created
- Skills earned during this run

**Archive Browser:**
- All completed research runs, searchable by topic/domain/date
- Filter: human-spawned vs. autonomous
- Each result: topic, duration, # sources, # skills earned, report link
- Insight extraction: what ATHENA's top learnings were from each run

### Tab 13: Diplomatic Simulation Theater

**Purpose:** Game-theoretic negotiation modeling for any bilateral or multilateral scenario.

**Layout:** Scenario builder (left) + game tree (center) + Nash analysis (right)

**Scenario Builder:**
- Select parties (2–8 nations or actors)

**Nash Analysis Panel:**
- Identified Nash equilibria for current scenario
- ATHENA's recommended US strategy (which path reaches best Nash for US interests)
- ZOPA visualization (Zone of Possible Agreement) for negotiation scenarios
- Leverage points: what US could offer/threaten to shift equilibrium
- Historical precedent: the 3 most similar historical negotiations with outcomes

**Pre-packaged Scenarios:**
- North Korea denuclearization (6-party)
- US-China trade normalization (bilateral)
- Iran nuclear framework 2.0 (multilateral)
- Ukraine peace negotiation (multilateral)

## Mobile Application (iPhone)

**Platform:** Swift 6 + SwiftUI + Whisper (local STT)

### Voice-First Interface

**Wake word:** "Hey ATHENA"
**Interaction model:** Voice in, structured brief out. The primary interface is conversation, not browsing.

**Home screen:**
- Current CHI score (large, centered)
- "Top 3 issues today" (AI-generated, updated hourly)
- Most urgent advisory (title + urgency badge)
- Push notification badge for new advisories above user's threshold

**Voice command examples:**
- "Hey ATHENA, what's the biggest risk today?" → 45-second spoken brief
- "Hey ATHENA, brief me on the situation in Taiwan" → 2-minute domain brief
- "Hey ATHENA, what does the CBO say about the infrastructure bill?" → direct answer
- "Hey ATHENA, run a quick simulation — what if we raised rates 50bps today?" → verbal Monte Carlo summary

**Briefing View:**
- Swipeable cards: World Risk / Economy / Defense / Climate / Legislation / Diplomacy
- Each card: 3-bullet summary, urgency indicator, "tap to expand" → full advisory
- "Read to me" button → TTS narration of current card

**Presidential Mode:**
- Toggled by role authentication
- 3 issues. Period. 1 recommendation each. Tappable for more.
- Designed to be fully read in 90 seconds
- Voice memo: record verbal brief → ATHENA transcribes and responds in text + voice

**Security:**
- Face ID / Touch ID required on open
- Classified content: requires additional authentication level
- Session timeout: 5 minutes of inactivity
- No data stored locally beyond credentials — all pulled from GovCloud
